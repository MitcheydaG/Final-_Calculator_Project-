# README

# Calculatrice du groupe

Il s'agit d'une calculatrice codée en architecture MVC, avec CustomTkinter comme GUI.

## Fonctionnalités

- La calculatrice présente deux faces principales : une capable de faire des opérations simples (la fenêtre principale), et une autre permettant de réaliser des calculs beaucoup plus poussés et scientifiques.

- Séparation entre le fichier "main" ( contient la logique de calcul ), le "view" ( crée l’interface graphique ), le "controller" ( gère les actions des boutons et relie la vue au modèle ) et le "model" ( contient la logique de calcul ).

## Prérequis

- Python 3.9+

- Customtkinter 5.2.2

- Darkdetect 0.8.0

- Packaging 26.0

## Utilisation

- Lancer le programme dans le fichier "main.py".

- La fenêtre principale permet de faire des calculs simples.

- Appuyer sur la flèche du haut de la fenêtre pour accéder à la calculatrice scientifique.

- L'horloge sert à ouvrir l'historique des calculs, où sont recensés tous les anciens calculs effectués sur la calculatrice.
